# Contributing

Propose a paper through [this repository's issue form](<REPOSITORY_URL>/issues/new?template=propose-paper.md).
Keep the proposal short and include a DOI, repository or project link where available. A curator decides
whether to build and release it.
People without access to this repository file the proposal as an issue on the public
master repository instead, and a maintainer stages it here.

Propose a skill or report a problem with shared tooling, governance or retrieval on the
[public master repository](https://github.com/HolobiomicsLab/asb-skill-collections/issues).
Domain content problems belong on this repository's issue tracker.

Read the master's
[contribution loop](https://github.com/HolobiomicsLab/asb-skill-collections/blob/main/docs/CONTRIBUTION_LOOP.md)
and
[content policy](https://github.com/HolobiomicsLab/asb-skill-collections/blob/main/governance/CONTENT_POLICY.md)
before proposing content. Do not include private data, credentials or unpublished sensitive material.
