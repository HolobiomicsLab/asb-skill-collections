## Install

From a local checkout, install selected skills with the public `asbb` tooling:

```bash
asbb install --repo <checkout> --skills <slug-a>,<slug-b> --collection <INSTALL_COLLECTION> --runtime agents
```

The collection's `USAGE.md` documents marketplace installation, search and grounding.
