# or fewer) as weak: a name match alone does not establish that the package is
# the tool, because the word may name something else in the record's collection
# (cooler, gambit, meteor, singularity). A weak name resolves only with
# corroboration from the record's own evidence.

# Derived, not curated: the lower-case entries of Webster's Second International
# Dictionary (1934, public domain; /usr/share/dict/web2 on macOS) longer than four
# characters, intersected with the normalised package names of Bioconductor and
# Bioconda on 2026-11-11. The dictionary is broad, so the list also holds names
# few would call words (limma, edger); for those the cost is only that the
# match must be corroborated. Regenerate when the registries grow.
