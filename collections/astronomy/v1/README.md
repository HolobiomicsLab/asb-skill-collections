## How to get this collection

Claude Code:

```text
/plugin marketplace add HolobiomicsLab/asb-skill-collections
/plugin install astronomy@asb-skill-collections
```

Codex CLI:

```text
codex plugin marketplace add HolobiomicsLab/asb-skill-collections
codex plugin add astronomy@asb-skill-collections
```

The marketplace entry installs from the public domain repository, so these commands need no read access.
