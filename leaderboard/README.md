# Contributor tables

These two files credit the people who contribute to the collections: reviews,
papers proposed, skills corrected. They are not a ranking of agents or models.

| File | Content |
| --- | --- |
| `annual-2026.jsonld` | contributions counted in 2026 |
| `career.jsonld` | contributions counted since the start |

Both lists are empty: no contribution has been counted yet. The rules for
counting are in [`.github/CONTRIBUTING.md`](../.github/CONTRIBUTING.md).

No agent-performance leaderboard exists. The evaluation material of the
collections is definitions only, with no validation; see
[`docs/evaluation-definitions.md`](../docs/evaluation-definitions.md).
