Contribute an improvement

Exercised a skill or workflow and found a better default, a missing step, an outdated tool, or a bug? Turn it into a contribution. Your text is scrubbed of file paths, emails, IPs, and secrets in your browser before anything leaves the page — then this opens a pre-filled GitHub issue you review and submit. Reviewers can promote it to a PR; merged contributions count toward the contributor leaderboard and co-authorship on the next release DOI.

Every report goes to the issue tracker of the public registry. The domain repositories are private: a maintainer carries each report into the domain repository. Four routes, in the same words everywhere:

  1. this skill is wrong or could be better: this form, or the skill feedback issue;
  2. a skill is missing: request it with this form (kind gap or composition) or the request issue, or propose yours with the skill proposal issue;
  3. a paper is not referenced: propose it;
  4. something technical failed (install, plugin, search, CLI, site, gates): report it.
